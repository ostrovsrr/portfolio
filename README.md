# rodion-ostrovskii.com

Personal portfolio. Plain static HTML and CSS, no build step.

- `index.html`, `projects.html`, `contacts.html` and one page per case study
- `styles.css` holds all styling, `theme.js` the light/dark switch
- `img/` holds images; `CNAME` keeps the custom domain on GitHub Pages

To preview locally, open `index.html` in a browser.

The previous React (Create React App) version is in the git history before this commit.
